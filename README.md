# Project Armor - Athlete Injury Risk Prediction

Project Armor is a machine learning project designed to predict athlete injury risk using physiological and training-related indicators. The project explores how machine learning models can identify patterns in athlete data and support safer training decisions.

## Overview

Athlete injury prevention is an important concern in sports training and performance monitoring. This project applies supervised machine learning techniques to classify injury risk based on selected health and performance indicators, such as heart rate, respiratory rate, skin temperature, blood oxygen level, and other athlete-related measurements.

The goal of the project is to demonstrate a complete machine learning workflow, from data preprocessing and feature scaling to model training, evaluation, and comparison.

## Features

* Data preprocessing and cleaning
* Feature scaling for model preparation
* Training of multiple machine learning models
* Model comparison using classification metrics
* Confusion matrix and evaluation visualization
* Injury risk prediction based on athlete-related indicators

## Machine Learning Models

The project compares several classification models, including:

* Logistic Regression
* Random Forest
* Gradient Boosting
* K-Nearest Neighbors
